# OnlineSchool 🎓

Платформа для онлайн-репетиторства, позволяющая преподавателям проводить занятия для широкой аудитории и монетизировать свои курсы.

## 🎯 О проекте

OnlineSchool решает проблему масштабирования репетиторства: преподаватели могут записать видео-уроки один раз и продавать доступ к ним неограниченному числу учеников, вместо того чтобы вести тет-а-тет занятия.

## ✨ Текущий функционал

- 🔐 Регистрация и аутентификация пользователей
- 📹 Загрузка и хранение видео-уроков
- 📚 Создание и управление курсами
- 💳 Покупка курсов (тестовый режим)
- 🔒 Безопасный доступ к материалам через временные ссылки
- 🎥 Просмотр курсов с проверкой доступа

## 🏗️ Архитектурные особенности

Проект разработан с упором на **чистую архитектуру** и **принцип единой ответственности**:

- **Модульность**: Четкое разделение на слои (API, бизнес-логика, работа с данными)
- **Заменяемость компонентов**: Легкая миграция с SQLite на PostgreSQL (планируется)
- **Безопасность**: Временные подписанные ссылки для доступа к оплаченным материалам
- **Масштабируемость**: Медиа-файлы хранятся в MinIO S3, готово к production-нагрузке

## 🛠️ Стек технологий

**Backend:**

- FastAPI (асинхронный фреймворк)
- SQLite (разработка) → PostgreSQL (production)
- MinIO S3 (хранение медиа-файлов)
- Uvicorn (сервер)

**Инфраструктура:**

- Docker & Docker Compose
- REST API

**Безопасность:**

- Временные подписанные URL для доступа к контенту
- Проверка прав доступа перед генерацией ссылки

## 📦 Установка и запуск

### Требования

- Python 3.9+
- Docker & Docker Compose
- MinIO (или любой S3-совместимый сервер)
- Uvicorn

### Запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Qwwery/OnlineSchool.git
cd OnlineSchool
```

2. Создайте `.env`

3. Поднимите инфраструктуру (MinIO S3 и др.)

```bash
docker-compose up -d
```

4. Примените миграции БД

```bash
alembic upgrade head
```

5. Запустите приложение

```bash
uvicorn main:app --reload
```

6. Приложение доступно на `http://localhost:8000`

## 🔐 Безопасность

Доступ к видео-материалам защищен системой временных ссылок:

1. Пользователь покупает курс
2. При запросе видео генерируется временная подписанная ссылка (срок жизни: N минут)
3. Ссылка действительна только для авторизованного пользователя с активным доступом
4. После истечения срока ссылка становится недействительной

Это предотвращает несанкционированный доступ и распространение материалов.
